# ASPI Engineering & Interiors

> Premium smart office fit-outs, workplace MEP engineering, statutory compliance management, and single-team turnkey delivery.

## Overview
ASPI operates as a single-team solution from concept to handover, emphasizing a **"SmartOffice-first"** approach. We eliminate the disconnect between interior design and building services engineering through 3D BIM coordination, precision MEP integration, and statutory compliance.

## Tech Stack
- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** Tailwind CSS + Vanilla CSS tokens
- **Icons:** Lucide React
- **Design Aesthetic:** Warm luxury architectural palette (`cream`, `sand`, `linen`, `terracotta`, `walnut`, `charcoal`), serif typography (`Playfair Display`, `Cormorant Garamond`), and responsive layouts.

## Key Features
- **Featured Projects Showcase:** Filterable portfolio across Corporate, Server Rooms, Healthcare, Banking, Retail, and Industrial projects.
- **Masonry Project Gallery:** High-resolution image grid with lightbox viewer.
- **Interactive Cost Estimator:** Real-time budget estimator by square footage, project type, and finish tier.
- **Core Services & Disciplines:** Tabbed deep dive into MEP Coordination, Turnkey Fit-Outs, Compliance Management, and Testing & Commissioning.
- **Leadership & Story:** Profile of Founding Director Brijesh Mishra, milestone stats, and corporate vision.
- **Clients & Partners:** Enterprise clients, testimonials, and OEM supplier brands.
- **Site Audit / Consultation Modal:** Interactive booking form with automated prefill from project modal and estimator.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
